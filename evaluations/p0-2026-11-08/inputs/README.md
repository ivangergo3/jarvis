# P0 evaluation inputs

All companies, quotes, figures, API versions, commits, and events in cases.json are synthetic fixtures. They do not assert actual product state or customer results. Evaluators receive these prompts and the named skill snapshot without answer rubrics. Use only the provided material and produce answers, without app implementation, external messages, live tests, or team configuration.

There are 19 skills with one normal and one boundary task each. This is a bounded behavioural sample, not a statistical reliability estimate or a controlled comparison against an unskilled baseline.
