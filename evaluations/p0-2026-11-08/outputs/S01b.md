# Normal task output

Acceptance criteria for manual filtered CSV export:

| ID | Scenario | Observable result |
| --- | --- | --- |
| CSV-1 | Manager requests export from the report | A manual CSV download is available from the existing report screen. |
| CSV-2 | Date range and employee filters are active | Exported records match those filters together; changing either filter changes the exported result accordingly. Proposed interpretation: all matching rows, not only a visible page; confirm if pagination exists. |
| CSV-3 | Manager has employees assigned to them | Every exported row is within their existing permitted employee set. Export cannot broaden access, including through an altered employee filter/request. |
| CSV-4 | Matching records exist | Each record includes employee name, date, hours and approval state with values corresponding to the report; headers identify those fields. |
| CSV-5 | Names contain accents, commas, quotes or line breaks | Reading the CSV preserves each name exactly as one field in one logical record, without corrupting accents, shifting columns or creating extra records. |
| CSV-6 | No records match | Export completes with an identifiable empty dataset. Proposed behavior: the same four headers and no data rows; confirm this output convention. |
| CSV-7 | User needs Excel comparison | Opening/importing the CSV in the agreed Excel environment preserves the four fields, accented names and numeric hours sufficiently for comparison; dates and approval states remain unambiguous. Locale/date and decimal conventions need agreement. |
| CSV-8 | Export action is used | Existing viewing permissions continue to apply; no scheduled export or integration is introduced. |

Unresolved: performance threshold and any export volume limit are not agreed. No numerical pass target is invented. Confirm pagination semantics and the proposed empty-file and Excel locale conventions before treating those proposals as agreed requirements. These are acceptance outcomes; no check has been executed and no library is chosen.
