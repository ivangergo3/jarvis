# Content ideation

## Inputs

Source notes, intended reader, recent topics if available, format and disclosure limits.

## Procedure

Find the useful observation, practical question or unresolved tradeoff in the source. Generate distinct angles only where they help selection; each should identify the reader benefit and the source fact that supports it.
Check overlap with supplied recent content and vary the insight, not just the hook. Name the missing detail needed to develop an idea rather than manufacturing a result or anecdote.
Use story frameworks only when the material fits. A reflection can stand alone without a moral, sales pitch or provocative ending. Respect an already-selected topic; do not restart ideation for a narrow edit.

## Output

A small set of differentiated ideas with source, reader, takeaway and optional opening or next question.

## Boundary

No invented experience, quotes, publication history or calendar commitments. Private notes stay private unless chosen for disclosure.
